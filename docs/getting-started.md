# Getting started — "hello mod" in 10 minutes

> **Note**: this is the legacy quick-reference. Most new modders
> will prefer the [step-by-step course](tutorial/01-hello-mod.md)
> with incremental progression. This doc remains as a dense
> overview.

Your first mod, end-to-end. We assume Snake Classic as target.

---

## 1 — Project scaffold

**Option A — use the framework scaffold (recommended)**:

```bash
# From a framework clone:
npx degit leteoworks/mod-template-snake-classic ~/projects/my-first-mod
cd ~/projects/my-first-mod
pnpm install
# Edit mod.json (id, metadata) + src/index.ts and run: pnpm watch
```

See [`mod-template-snake-classic`](https://github.com/leteoworks/mod-template-snake-classic)
for details.

**Option B — from scratch**:

```bash
mkdir my-first-mod
cd my-first-mod
npm init -y
npm install -D esbuild typescript
```

Minimum structure:

```
my-first-mod/
├── mod.json
├── src/
│   ├── index.ts
│   └── globals.d.ts      # declares `host` as global ambient
├── build.mjs             # esbuild pipeline
├── tsconfig.json
├── dist/                 # generated by esbuild
└── package.json
```

Before packaging or publishing, lint with:

```bash
node /path/to/framework/scripts/mods/validate-mod.mjs .
```

(or `pnpm mods:validate <path>` from the framework repo). The
validator checks manifest + App Store §3.3.2 compliance without
needing the game running.

## 2 — `mod.json`

```json
{
  "manifestVersion": 1,
  "id": "tunick.hello-mod",
  "version": "0.1.0",
  "target": { "gameId": "snake-classic", "gameVersion": "^2.0.0" },
  "engine": { "preferred": "quickjs-declarative-ui", "fallbacks": ["isolated-vm"] },
  "requires": { "hostApi": "^1.0.0" },
  "entry": "dist/index.js",
  "permissions": [
    {
      "type": "events",
      "subscribe": ["GAME_OVER"],
      "rationale": "Greets the player when the game ends"
    },
    {
      "type": "settings-ui",
      "rationale": "Adds a tab with a toggle to enable the greeting"
    }
  ],
  "metadata": {
    "name": "Hello Mod",
    "description": "My first mod — a greeting at game over.",
    "author": "Your Name",
    "license": "MIT"
  }
}
```

Rules to remember:
- `id` must be globally unique. Convention: `<your-handle>.<mod-name>`.
- `version` is strict SemVer.
- Each permission needs non-trivial `rationale` (the player sees it).

## 3 — `src/index.js`

```js
// Simple mod — a toggle in settings + a greeting at game over

host.registerSettingsTab({
  id: 'hello-mod',
  title: 'Hello Mod',
  icon: 'mood',
  sections: [{
    kind: 'group',
    title: 'Greeting',
    fields: [{
      kind: 'toggle',
      label: 'Enable greeting at game over',
      binding: 'greetOnGameOver',
    }],
  }],
})

host.subscribeEvent('GAME_OVER', async ({ finalScore }) => {
  const enabled = await host.storage.get('greetOnGameOver') ?? true
  if (!enabled) return

  host.log.info(`You ended with ${finalScore} points. Good game!`)
  host.dispatch('MOD_NOTIFICATION', {
    text: `Good game! Score: ${finalScore}`,
  })
})

host.registerHook('onActivate', () => {
  host.log.info('Hello Mod activated.')
})
```

## 4 — Build

```json
// package.json
{
  "scripts": {
    "build": "esbuild src/index.js --bundle --outfile=dist/index.js --format=iife --target=es2020"
  }
}
```

```bash
npm run build
```

Produces `dist/index.js` ready to load.

---

## 5 — Sideload in the game

Locate the game's `userData` directory (platform-dependent):

- macOS: `~/Library/Application Support/snake-classic/mods/`
- Windows: `%APPDATA%/snake-classic/mods/`
- Linux: `~/.config/snake-classic/mods/`

Copy your project:

```bash
cp -r ~/my-first-mod ~/Library/Application\ Support/snake-classic/mods/tunick.hello-mod/
```

Expected final structure:

```
~/.../snake-classic/mods/tunick.hello-mod/
├── mod.json
└── dist/index.js
```

---

## 6 — Open the game

1. Launch Snake Classic.
2. Go to Settings → Mods → Community.
3. Your mod appears as "Detected (sideload)".
4. Click "Activate".
5. Accept the permissions prompt.
6. State changes to "Active".
7. Your "Hello Mod" tab appears in Settings.
8. Play a game. When it ends you'll see the log and the
   notification.

---

## 7 — Iterate

Changes to `src/index.js`:
1. `npm run build`
2. Restart the game (mods load at boot).

For hot-reload during development, see
[../implementation/enabling-mods.md](https://github.com/leteoworks/my-game-fw/blob/main/docs/mods/implementation/enabling-mods.md)
about `dev mode` (not standard; depends on the game).
